# ClearPix – Watermark Remover

Browser-based watermark remover. No server, no limits, photos never leave your device.
Auto detect or paint over the watermark, tap Remove, save the full-resolution PNG.

## Deploy
1. Create a new GitHub repo and upload: index.html, vercel.json, .gitignore, README.md
2. vercel.com > Add New > Project > import the repo
3. Framework Preset: Other. Build command and Output directory: empty. Deploy.

Use only on photos you own or have permission to edit.
